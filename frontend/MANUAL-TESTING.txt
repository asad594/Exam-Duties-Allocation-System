PROBLEMS?
--------------------------------------------------------------
"Cannot reach the server. Is the API running on port 5080?"
     -> Terminal 1 is closed or the API stopped. Do Step 1.4 again.
Page does not open at localhost:5173
     -> Terminal 2 is closed. Run "npm run dev" again.
Counts are different from this guide
     -> old test data. Do Step 1.3 (drop) then 1.4 again.
